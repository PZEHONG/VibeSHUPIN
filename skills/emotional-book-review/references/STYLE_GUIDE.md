# 四类情感风格引擎

此文档是选择情感“切口”和声音的参考，不是要求每篇都按同一个结构生成。

## 情感共鸣（empathy）
- 关键词：曾经的自己、关系、没说出口、成长里的矛盾、被理解。
- 最佳入口：书中角色/观点与读者正在经历的具体困境相互照见。
- 节奏：生活小细节 → 角色选择 → “我也如此”的顿悟。
- 措辞：贴近日常说话；允许一两个反问，不滥用“你是否也……”。
- 读者收益：获得理解和陪伴，而非被要求立刻改变。
- 适用例：家庭关系、成长小说、心理困境、友谊与信任。
- 避免：无差别移植失恋套路；“所有人都会这样”式绝对化。
- 结尾思路：被看见的心情、允许不完美、一个具体的心境转变。

## 文学治愈（healing）
- 关键词：松弛、允许、温柔、归属、缓慢修复、小小希望。
- 最佳入口：一处值得安静凝视的原著意象/关系/行动。
- 节奏：真实伤口 → 细小的温暖 → 不否认伤口的接纳。
- 措辞：简洁、留白、形象；让“物”承载情绪，不堆“月光/风/花”。
- 读者收益：读完觉得被安稳地放下，而非被强迫积极。
- 适用例：成长、人与自然、人与人之间的善意、散文随笔。
- 避免：暗示一本严酷的悲剧“只要想开就会好”；心理疾病相关故事避免轻率许诺治愈。
- 结尾思路：微小却可信的希望、与自己和平相处。

## 遗憾告别（farewell）
- 关键词：错过、离开、余温、放手、未寄出的信、珍惜与分寸。
- 最佳入口：书中真实存在的距离、分离或阶段终结。
- 节奏：难以说出口 → 失去后的细节 → 告别的意义。
- 措辞：感伤但有尊严，尽量写具体“失去什么”，少喊口号。
- 读者收益：理解告别不等于否认曾经存在的意义。
- 适用例：离别、悼念、迁徙、青春、时间流逝、失落。
- 避免：对没有离别主题的书强行创造恋爱故事；浪漫化纠缠、牺牲、被伤害。
- 结尾思路：无法重来，但能承认发生过；收束在那本书独有的意象上。

## 人生感悟（reflection）
- 关键词：选择、承担、勇气、边界、自我价值、时间与有限性。
- 最佳入口：一个具体矛盾或书籍核心概念，不是大道理先行。
- 节奏：习以为常的误区 → 书中的另一种视角 → 具体的认知调整。
- 措辞：平实、有洞见、读后愿意停下来想一想。
- 读者收益：能解释一种真实困境，带走一条有分寸的理解。
- 适用例：传记、哲学、心理学、成长类书、经典现实主义文学。
- 避免：把所有作品总结成“努力就能成功”；误引心理学理论；将复杂的社会困境归咎于个人心态。
- 结尾思路：新的选择尺度、对有限人生的清醒体认。

## 叙述与听感

先选有材料支持的切口，再匹配情绪；上面的节奏仅为参考。
默认采用 [NARRATIVE_LONGFORM.md](NARRATIVE_LONGFORM.md) 的中长篇叙事讲解；用户指定短篇情绪导读时按 [EMOTIONAL_LEAD.md](EMOTIONAL_LEAD.md) 确定处境、锚点、推进与落点。情绪服从作品，四种风格不是固定脚本，也可指定评论体、金句书摘体或情感散文体。
允许人物动作、原文细节、概念冲突直接开篇，不必反问或报幕。每段推进同一个问题，自己的理解可藏在动作和句间关系里；需要解释时把桥梁说清，不把所有理解都写成“这说明”。正文不固定句数、单句字数或短句比例；字幕在确认后按语义拆屏，不改原文。
每个判断回到可信的行动、关系或细节；生活映射用于解释，不替代书本。冷峻作品可保留不安、矛盾和未解决的问题。
书名可以自然口播一次，也可只屏显；口播与书名卡允许同步。英文副行可选，不决定中文句式。引用与署名按 [QUOTING.md](QUOTING.md) 核查。

## 书籍类型对照（启发，不是硬规则）

| 书籍主题 | 主风格建议 | 最好抓取的内容 |
|---|---|---|
| 青春与成长 | 情感共鸣 / 遗憾告别 | 特定关系、未说出口的话、一次选择 |
| 人与人相处 | 情感共鸣 / 文学治愈 | 被理解的瞬间、难以协调的差异 |
| 失去与生死 | 遗憾告别 / 人生感悟 | 逝去后的生活细节、生命有限性 |
| 散文与自然 | 文学治愈 | 原著真实的场景与物象 |
| 心理学与哲学 | 人生感悟 / 文学治愈 | 准确概念、常见误区、应用边界 |
| 现实主义与苦难 | 人生感悟 / 情感共鸣 | 人物处境、社会背景、韧性（不抹平苦难） |
| 商业管理和工具书 | 人生感悟（有限适用） | 能够转化成人生选择的原书观点 |

## 五条反套路规则

1. 不要每篇都是“这是我听过最遗憾的一句话”。
2. 不要每本都使用“月亮/风/蒲公英/岁月”同一组意象；以原著特有意象为优先。
3. 不要频繁使用三连句：“不是……不是……而是……”。
4. 不是每篇都要“谢谢你来过”；该冷静时可以冷静收尾。
5. 不要把编造的书中事件写得像亲眼读到的一样。

## 句法建议（任选，不得拼贴成固定模板）

- 从一个具体的生活场景开头，而不是先赞美这本书。
- 用一句中短句改变上一段的情绪方向。
- 让书的独有符号出现两次：先作为事物，后作为心情。
- 最后一句可以是发现、接受、疑问，不必是劝告。
