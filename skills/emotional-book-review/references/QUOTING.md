# 原文引用与出处核查

## 引用记录

每条候选引文保留以下字段，先在内部底稿记录，确认后移交项目事实表。事实表、来源说明与配音正文分开。

| 字段 | 内容 |
|---|---|
| 编号 | Q1、Q2等，便于逐条追踪 |
| 逐字文本 | 包含必要标点，与所选版本对应 |
| 作品与作者 | 具体书名；不能只凭作者名字判断所属作品 |
| 译者与版本 | 译者、出版社、年份等能查到的信息；不详写未知 |
| 位置 | 章、页码或电子书位置；不同版本页码不能混用 |
| 语境 | 谁说的、对谁说、什么处境；是否反讽、否定或条件句 |
| 依据与状态 | 可读取正文／书页／授权试读／二手引述；已核实或待核 |
| 使用理由 | 支撑哪个具体判断，为什么需要保留原话 |

## 条件处理

- 可读取原书、清晰书页或授权试读：逐字核对，并说明来源覆盖范围。
- 用户粘贴明确作为书摘的文字：可注明“用户提供片段，版本未独立核验”；不把它宣传成已与出版物核对。若明显矛盾或来自用户的模糊记忆，先核查或排除。
- 用户笔记、网传名句、其他书评：作为检索线索；不能直接当原著引文。多个转载同一句不能替代原始出处。
- 参考视频配音、ASR转写、视频里署名给某本书的句子：按二手线索处理。转写校对不能替代出版物出处核验；未核验前只学习句间关系、节奏与情绪推进，不复用为书摘，不以去掉引号的方式洗成原创评论。
- 有联网工具：优先原书、出版社试读、正式电子书；报道或访谈须明确属于二手引述。搜索摘要不等于已核对正文。
- 没有工具或查不到：排除待核句；只能转述其他已确认的情节或观点。书籍主题也不明时要求简介。
- 引句属于人物或叙述者：按实际声音介绍，不能改成“作者教我们”。

引用与评论要有清楚边界。可采用“情境→短引→解释”，也可先引后交代；不固定位置，不要求开头结尾都放名句。
一条短视频通常零到一处短引即可；长视频按论述需要增加。不要用大量摘录替代评论，不把数量或比例当成授权标准。
原句长于字幕容量时按语义跨屏显示；需要缩短时另选连续完整片段，不能删掉影响原意的条件、否定或上下文。
原创评论的英文副行是屏显翻译；原著中译句的英文副行也不能标成作者英文原句。

## 交给视频工作流

审稿时展示简短来源说明；用户确认后把引用记录放入事实表。
script.json 的 segments[].text 只含已确认正文，不混入页码、来源网址、核查说明或编辑标签。
closing.attribution 仅在 closing.text 为已核实引文且记录可追溯时填写。原创落点省略 attribution，不能整段署作者名。
