# 中长篇叙事讲解：用故事推进理解

用于默认 8–15 分钟书评，先以预计 10–12 分钟构思；时长是范围而非填充目标。用户指定的篇幅、风格和剧透边界优先。先完整讲清楚，再靠真实朗读或配音测时。

## 1. 确定讲述范围和材料

- 记录书名、作者、版本、平台、目标观众、预计时长、讲整本还是人物线／主题／章节，以及剧透边界。未指定时尽量不剧透关键转折；需要讲结局才能支撑主题时先说明并确认，或选择无需关键剧透的范围。
- 小说可以沿人物行动与事件推进；非虚构书沿作者的问题、概念与论证展开，不虚构人物或戏剧冲突。读者不熟悉原书时只补理解当前内容必需的背景。
- 建立叙事与证据底稿：`顺序/章节｜事实或概念｜来源与位置｜关联观点｜其他解释或限制｜待核实项`。区分原书事实、作者观点、人物说法和自己的解读；逐字引文另按 QUOTING.md 登记。
- 原文或可靠材料不足以支撑长稿时，查找可靠资料或请求用户提供正文、摘录、笔记；仍不足就缩小范围或交较短稿并说明，不用简介和评论假装掌握全书，不编造情节、心理或引用。

## 2. 章节提纲

先确定贯穿全片的问题或理解，再选择推进路线。通常包括引子、必要背景、若干叙事章节与回扣；章节数依作品调整，不必每期凑齐。每章标注：发生了什么或作者提出什么、这一段为什么必要、观众多理解了什么、对应证据和下一章的连接。删去不服务本期的事件和概念。

叙事节点依次考虑：交代必要情境 → 准确讲述行动、变化或论证 → 解释细节为何重要 → 必要时讨论另一种解释或限制 → 自然引向下一节点。不是每个节点都要做完所有步骤；评论紧贴证据，避免把个人推断写成原书事实。

## 3. 成稿与审查

- 开头以具体矛盾、行动或问题建立期待，明确作品及讲述方向；不用夸张承诺。情节须按作品实际关系组织，必要的回叙应让观众听得懂。
- 人名、关系、代词和转场以一次听懂为准。解释文学写法或观点时，说明细节与判断之间的关系；不强制鸡汤、升华或唯一答案。
- 第一轮核事实、引用、版本、人物／作者立场和剧透；第二轮朗读检查叙事连贯、分析是否有依据、章节是否各有新增信息、结尾是否回应开头。剧情复述过长就删去无助于理解的内容，不为表现深度堆抽象概念。
- 根据预计语速和留白粗估字数，实际朗读或配音决定时长。未经测量只标预计；短篇需求继续走 EMOTIONAL_LEAD.md，不受长稿默认结构限制。

## 4. 确认与移交

默认交付本期切口、剧透说明、章节提纲、完整口播正文、三个备选标题、配音提示和简短来源说明。提纲、来源、编辑备注和配音提示不进入配音。纯文案请求以干净正文为主；重要材料限制与剧透提示放正文外。用户确认后才进入视频工程，依据真实配音时间轴安排分镜与字幕。
