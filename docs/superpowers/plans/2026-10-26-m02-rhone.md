## 参考观察与选择

参考文件 1452×1080、30fps、644 帧、21.466667 秒。已逐帧解码为 references/rhone-study/frames，9 张连续帧拼版覆盖全部帧。拼版用于连续性观察；细节另看原尺寸关键帧，不能把缩略图检查当作逐帧原尺寸精修。

| 帧段（从0开始） | 观察 | M02 落实 |
|---|---|---|
| 0–131 | 水面、细长暖金倒影，桥逐步显露 | 蓝色大底、稀疏暖色焦点、方向性水面笔触 |
| 132–247 | 推近桥洞，近桥遮挡，远岸相对稳定 | 按镜头设计缓慢推移、前景遮挡与纵深 |
| 248–359 | 穿过桥洞后接近两船，船身从两侧扩出 | 主体稳定，前后层有不同位移，不用满屏纹理漂移 |
| 360–447 | 岸边人物逐渐成为焦点 | 灯光、人物与环境统一冷暖关系 |
| 448–575 | 人物抬手，视野向上/后移，画面逐渐还原绘画 | 局部动作 + 克制运镜；静态笔触附着物体 |
| 576–642 | 完整画面保持 | 结尾落定、保留旁白后留白 |
| 643 | 黑帧 | 不复刻参考片尾黑帧 |

现版问题：高反差同尺寸短笔触随机铺满、几何边缘太干净、整体赭黄且光照均匀、层级与局部动态不足。

选择多尺度底色/方向笔触/局部光照 + 分层运镜。在现有纯 Remotion 约束下可复现、可编辑。仅叠滤镜不能改善空间；改为 AI 生图/视频会改变现有生产路线，本次不采用。
