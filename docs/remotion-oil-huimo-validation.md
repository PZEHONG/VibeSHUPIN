# M02 挥墨体字幕优化

日期：2026-10-26。工程：projects/bainiangudu-remotion-oil。

按用户要求调整 M02 主题字幕，让字幕更自然并使用挥墨体。

- 使用用户先前六片山项目保留的本地文悦挥墨手书字体，复制至 engine/fonts/WenYue-HuiMoShouShu-J.otf。M02 单独加载该字体，缺失时明确报错；等待加载后测量排版，不使用合成加粗。字体内容计入渲染摘要，静态字体按实际字节更新。
- 中文上限 72/66/60px，按句长选择并以实际字体宽度缩小；字距 .018em、行高 1.28。原字幕中心、安全区、中英文文案与时间轴沿用。
- 重横带改为随文字宽度、行数变化的柔和椭圆暗影，配象牙白文字与轻阴影；约 0.16 秒的平滑淡入淡出由当前帧计算，短字幕相应缩短过渡。
- M01 保持原字体和字幕视觉配置。没有重新配音或修改镜头；没有添加音源。

验证结果：

- 常规回归 45 项：44 通过，1 项需显式启用的真实渲染检查跳过；随后单独启用并通过该检查，覆盖 M01/M02 各自 16 字、18 字、双行各 18 字与 60 个宽英文字母，共 8 种组合。
- 本地字体资源测试先失败再通过，验证 M02 挥墨体静态复制、旧缓存替换，以及 M01 无挥墨体时仍可准备资源。
- TypeScript 类型检查通过。已查看走廊、金鱼、雨停场景静帧，中文为实际挥墨体，背景油画透出；review/huimo-preview.jpg 为本次四帧预览，旧 sheet.jpg 仍为历史记录。
