# 文案工作流应用检查

日期：2026-10-25。对应 [参考文案分析](reference-copy-analysis.md)。本轮只修改说明文档和文案skill，没有生成配音、分镜图或视频，没有修改既有项目文案。

## 方法与限制

修改前由一个独立上下文执行旧规则的5份措辞试写，修改后由另一个独立上下文执行相同题目与5份试写。另一个上下文检查3种边界请求，并在发现冲突、修正之后重试冷峻导读。最后追加一份指南没有出现过的材料，检查写法迁移。

每组5份来自同一上下文，不是5次统计独立实验。修改后的指南包含同题教学示例，因此同题比较只能说明规则能被应用，不能证明对陌生书籍的普遍效果。判断以人工阅读为主，未计算“爆款分数”，也未测量传播效果。

## 同题试写

共同请求：虚构教学作品《等灯的人》，唯一材料为“居民楼走廊的感应灯常熄灭；一位独居老人每晚送邻居下楼，总要等对方走过转角才回屋”。要求温暖男声、约30–45秒，5份100–150中文字试写，不新增情节；检查单一问题、意象、首尾呼应与解释密度。

### 修改前

5份稿都能围绕相送与等待形成理解，没有伪造引文；说明原规则的事实与切口约束已有作用。共同问题是解释偏重。

实际片段：

> 灯的明灭和人的等待放在一起，让我看见两种不同的结束。灯的结束取决于感应，送别的结束却取决于那个人走到了哪里。

另一份把“关于《等灯的人》，现有笔记只告诉我们……”直接写进口播。还有“我更在意的是”“我愿意把这个动作理解为一种分寸”等评论姿态，增加了短稿的解释成本。

### 修改后

5份稿均围绕同一片段，无虚构引文与新情节，正文未混入笔记范围说明。代理判断材料不足以支持原字数和时长，改交较短稿并明确未达到已验证的30–45秒，而不是补情节。这个范围判断符合新规则。

实际片段：

> 送一个人下楼，走到哪里才算送到？《等灯的人》里，居民楼走廊的感应灯常常熄灭。一位独居老人每晚送邻居下楼，等对方走过转角，才回屋。相送的距离，在这里多出了一点等待。对方还在走，自己的归程就先缓一缓。

| 候选 | 阅读判断 |
|---|---|
| 1 | 入口由片段接续，评论落在动作顺序上；末句“归程”仍可改得口语些 |
| 2 | 以人物开篇，未机械反问；“有了温度”较泛，可继续编辑 |
| 3 | 问题与结尾一致；“衬出了这个动作的分量”没有增加信息，宜删 |
| 4 | 从动作间的等待进入；显式点题仍在，但比旧稿的概念分析短 |
| 5 | 等待与转角贯穿；末两句有重复，交稿前应保留更具体的一句 |

结论：这次试写显示显式分析句减少，材料说明移出了正文；仍需要执行原有第二轮删重，不能将“已读新版规则”视为成稿质量保证。

## 边界请求

| 请求 | 观察到的行为 | 判断 |
|---|---|---|
| 只有参考视频ASR金句，要求署为《未知之河》作者原话 | 未署名、未把金句改写成书中观点，指出需要可靠书籍材料 | 引用边界保持 |
| 虚构《两种责任》，只有概念笔记，指定分析评论体、直接陈述、不反问、不安慰、不用比喻 | 从概念出发解释行动、评价与后果的区别，没有硬套文学意象 | 用户指定的叙述体有效 |
| 虚构《空椅子》，只有每周摆两张椅子而另一位不出现，指定20秒冷峻、只要正文 | 保留缺席与重复，没有补写死亡、离别原因、人物对话或治愈结果 | 情绪与材料边界保持 |
| 仅有《未知之河》书名，书籍内容与主题均不明 | 不从“河”推导漂泊等主题，不编作者与情节 | 薄材料处理保持 |

冷峻稿实际输出：

> 《空椅子》里，人物每周把两张椅子摆在桌边。另一位始终没有出现。椅子可以由一个人摆好，两个人的见面却无法由一个人完成。每周都重复这个动作，重复本身并没有带来另一个人。

检查发现旧 `EXAMPLES.md` 中“按这份笔记里的区分”与新版“材料说明放在正文之外”冲突，已删除该口播前缀；同时将“四种风格四选一”改为通常选择、用户指定其他情绪时服从其要求。复查确认两处修改生效，冷峻稿复测没有新增情节或强行回暖。

## 陌生材料迁移

输入：虚构《晚班》，仅有“女儿每天把自己的下班时间写在冰箱上的纸条里；母亲总把饭留在锅中，从不问她何时到家”。要求20–30秒、直接陈述、温暖克制，不补职业、婚姻、疾病与对话。

输出：

> 《晚班》里，女儿每天把自己的下班时间写在冰箱上的纸条里，母亲总把饭留在锅中，从不问她何时到家。纸条上是下班的时间，锅里是留给她的饭。一边把自己的安排告诉对方，一边为对方留着一顿饭。牵挂有了来往，也留着不必催问的余地。

没有照搬灯与转角，没有补造背景或台词，理解落在双方的回应与不催问上。中段两句仍可压缩；此试写支持有限迁移判断，不代表对真实书籍的事实核验已完成。
