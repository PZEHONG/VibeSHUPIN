# 当前文案：叙事讲解，再适配字幕

当前书评为温暖男声纯旁白。写作唯一主入口是 [emotional-book-review](../skills/emotional-book-review/SKILL.md)，本页负责视频侧的篇幅与移交，不另设写作模板。

## 默认路径

1. 依据书名、笔记或正文建事实与引用底稿。参考视频转写只能提供写法线索，不能证明引文属于该书。
2. 默认8–15分钟叙事讲解型深度书评，先以10–12分钟构思。按 [中长篇叙事讲解](../skills/emotional-book-review/references/NARRATIVE_LONGFORM.md) 确定范围、观众、剧透边界，整理叙事与证据底稿，再写章节提纲。
3. 小说沿人物与事件展开，非虚构作品沿问题、概念或论证展开；围绕同一问题筛选节点，在关键处解释、比较，避免只复述。用户指定短篇时可用 [情绪导读指南](../skills/emotional-book-review/references/EMOTIONAL_LEAD.md)。
4. 证据不足时补充材料、缩小范围或交较短稿并说明，不虚构情节、观点或引文。结尾回应开头，不强行回暖。
5. 分两轮核查事实与朗读听感：检查分析依据、剧透、章节推进和人物关系，把来源说明移到正文之外。未实际朗读或配音测量时仅标“预计”。
6. 成稿先交用户确认。确认前不写工程稿、不配音、不做分镜。用户已明确批准的后续操作按既有授权执行。

## 量与节奏

总时长包含片头尾、句间停顿与口播。默认8–15分钟，先以10–12分钟构思；先留片头尾和停顿，再用约4–5字/秒粗估，温暖男声放慢后须实测。材料不足就补充资料、缩小范围或说明后缩短，不靠换词复述凑长。

听众试读和发布数据复盘按 [反馈指南](../skills/emotional-book-review/references/REVIEW_AND_FEEDBACK.md) 执行；没有真实反馈或数据时不臆造，不阻塞文案交付。

先写完整、自然的中文句子，不固定句数、句长或短句比例。不把字幕每行≤18字当作口播句长限制。只读一遍难以听懂时，先理顺指代和句间关系，再考虑修辞。

## 确认后移交

- 已确认正文按朗读意群进入 `script.json` 的 `segments[].text`；标题、来源、编辑卡、配音提示不入正文。
- 引用记录单独保留版本、位置、语境、来源与状态，见 [QUOTING.md](../skills/emotional-book-review/references/QUOTING.md)。原创落点不署作者名。
- 字幕按真实旁白的停顿、语义拆屏，每行≤18字，一个完整句可跨多屏。拼接后保持正文原字原序，不为排版改写引文。
- 配音后以 `audio/timings.json` 决定片长和镜头；不以预设四拍秒数覆盖实际时间。
- 改文案时先按用户意见修订；需要重配音或改分镜时同步对应材料，不能用旧配音配新字幕。
