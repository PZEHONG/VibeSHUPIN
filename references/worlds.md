# 七套书评 AI 绘画外观规格（S01–S07）

> **历史 Canvas 专用**：新工程默认纯 Remotion，主题 M01 文学纸艺，见 [Remotion 引擎指南](remotion.md)。本文仅用于显式 `--renderer canvas` 或 `--world` 的书评绘画与旧工程维护；C/B 也仅兼容旧工程。命令与清单见第八节。
> 成片固定 **1080×1920、9:16、30fps**。坐标、字幕与底板以 [vertical.md](vertical.md) 为准，不沿用旧横屏坐标。
> 声音只有温暖男声旁白：**无伴奏、无音效、无第二音源**。视觉模板不改变这条规则。
> 六宫格审核图的阅读顺序：上排 S01／S02／S03，下排 S04／S05／S06；S07 单独用同一场景审核。图中“窗边读书的人”只是统一比较场景，不要求每本书都画同一个人、同一间房。

## 一、选哪一套

| ID | 外观 | 首选文案与题材 | 画面识别点 |
|---|---|---|---|
| S01 | 暖光纸感油画 | 文学治愈、普通人的生活、温暖而克制的人生感悟 | 暖灰与赭色，可见油画笔触，小面积琥珀光 |
| S02 | 森系手绘绘本 | 自我接纳、情绪内耗、休息、重新开始 | 鼠尾草绿与奶油白，水粉色块、铅笔边缘，温柔但不幼稚 |
| S03 | 蓝灰胶片插画 | 遗憾告别、孤独、关系疏离、悬疑作品的情感解读 | 蓝灰低照度，少量暖光，背影与空位，细颗粒 |
| S04 | 淡彩水彩散文 | 散文、记忆、亲情、时间 | 透明水彩、烟灰蓝与浅褐，纸白留空、边缘晕染 |
| S05 | 黑白版画 | 现实文学、劳动、命运、尊严、沉重主题 | 黑白刻痕、明确轮廓，少量暗赭色点光 |
| S06 | 超现实纸艺 | 自我认知、选择、成长、抽象观念 | 可见剪纸边缘和层间投影，一个清楚的视觉隐喻 |
| S07 | 电影静帧 | 现实文学、命运、离别、雨夜、需要真人电影感的书 | 35mm 胶片、单一主光源、浅景深、低饱和、颗粒与暗角，同一主角跨镜 |

### 与四种书评文风对应

| 文案主风格 | 优先 | 按内容调整 |
|---|---|---|
| 情感共鸣 | S03 | 偏温暖的生活场景选 S01；要真人电影感选 S07 |
| 文学治愈 | S01 | 偏轻盈、自我接纳选 S02 |
| 遗憾告别 | S03 | 偏回忆与散文选 S04；雨夜/窗边选 S07 |
| 人生感悟 | S01 | 现实题材选 S05；抽象观念选 S06；余华式冷峻现实选 S07 |

- 拿不准先用 **S01** 做代表镜头，再按书籍主题调整。
- 一条片只用一套主画风。镜头远近、人物动作、光线可以变化，画材与角色设定保持一致。
- 题材、时代和地域优先于默认映射。温暖男声不等于所有作品都要画成阳光治愈。
- 七套是制作模板，不是抖音流量排名；不得据此承诺热门、涨粉或带货效果。

## 二、共用的竖屏、文字和声音规则

### 画幅与安全区

| 元素 | 本工作流规格 |
|---|---|
| 输出 | 1080×1920，30fps，9:16；生成素材也优先竖幅 |
| 顶部小字区 | y=90–200，x=62 起，最多两行；书名卡用 y≈292–462 |
| 内容区 | y=240–1380；关键人物面部、手部、书籍意象不压字幕 |
| 左右边距 | ≥60px；最右侧避免关键信息，另按平台预览检查按钮遮挡 |
| 字幕底板 | 从 y=1400 起渐暗，具体强度按画面亮度调整 |
| 字幕位置 | 块中心 `SUB_Y=1500`，中文主行约 76–78%H，英文副行约 81–84%H，底边 ≤1594 |
| 底部留空 | y≥1600 只留低信息量背景，给平台 UI |
| 镜头运动 | 预留轻微裁切余量；缩放后重新检查人物与字幕安全区 |

字幕沿用 [vertical.md](vertical.md)：中文 68px（≤13字）/ 62px（14–16字）/ 54px（>16字），一行不超过 18 字，行距为字号的 1.38 倍；英文副行 27px、单行、≤60 字符，仅中文单行时出现；淡入 0.26s、淡出 0.2s，不重叠。使用旁白原文和真实停顿，字幕永远最后画。

- 中文可用 Noto Serif SC 或 Noto Sans SC；一片固定字幕字族，不随镜头切换。
- 全片字幕的金色表示关键意象，玫红表示痛感词，一句最多染一处；不要把场景里所有金色和红色物体都解释成标注。
- 场景配色与后期字幕配色分别管理。S05 的黑白限制作用于绘画，字幕仍遵守统一规范。
- **不要求所有亮物发光，不统一叠加强辉光、暗角或颗粒。** S04 的纸白与 S06 的纸层不能被后期效果抹掉。
- 字幕、书名、作者、引文和封面文字统一后期排版；不让绘画模型生成准确文字。
- 配音、镜头切点与片长取实际 `audio/timings.json`，不为画风预设固定秒数，不安排音乐卡点。

### 本片视觉设定卡

正式出图前，在工程的 `storyboard.md` 写清：

| 字段 | 必填内容 |
|---|---|
| 主画风 | S01–S07 的一个编号及选择原因 |
| 书籍锚点 | 1–2个有依据的人物、关系、物件、地点或概念；附事实来源 |
| 时代地域 | 原著场景准确；不确定处标记待核实 |
| 角色 | 年龄段、脸型、发型、服装、配饰、身材比例、角色参考图 |
| 视觉母题 | 1个反复出现的物件或空间（伞、窗、灯、纸条、路口），全片不换 |
| 色与材质 | 主色2–3种，笔触／纸张／刻线／纸层／胶片的固定规则 |
| 色彩走向 | color script：开场冷/暗 → 中段强调色 → 落点回暖或更冷 |
| 光线 | 光源方向、时间与情绪变化；不强制结尾转暖 |
| 连续性 | 角色朝向、空间关系、道具位置、参考图编号 |
| 出图记录 | 实际使用的模型、版本、提示词、参考图；支持时再记录 seed 等参数 |
| 后期运动 | 推近、拉远、平移或纸层视差；明确哪一个主体在动 |

逐镜标记 **原著场景／读者生活映射／情绪隐喻**。自行设计的动作与物件不得冒充书中事实。
事实要求沿用 [storyboard.md](storyboard.md) 第三节；只有书名、没有足够事实时，不编造角色、年代或情节。

## 三、七套外观的具体规格

下列色值是试制建议，并非对审核图的像素测量。出图以材质与整体关系为准，不依赖模型精确复现十六进制色值。

### S01 暖光纸感油画

**底与材质**：真实可见的油画笔触，纸面／画布纤维，边缘有绘画感，脸、手和书籍轮廓仍清楚。保留厚薄变化，避免全图厚涂成一团。

**建议配色**：暖灰 `#A99B8A`、赭石 `#A46D43`、米白 `#EFE3CC`，琥珀点光 `#D79B4A`。暖光只占局部，不把整张画染成金黄色。

**构图与叙事**：窗边、门口、街角、旧桌等生活空间；用放下物件、挪动椅子、停步回望等具体动作承载情绪。不要每镜都画读书的人。

**运动**：轻微推近道具或人物、缓慢平移；笔触固定在画面上，不随机闪动。光晕适度，禁止满屏粒子。

**完整提示词模板**：

> 为一部情感书评短片绘制单张9:16竖幅叙事插画。手绘油画与细腻纸感结合，笔触可见、厚薄有变化，但人物和物件轮廓清楚。暖灰、赭石、米白主色，小面积琥珀光，低饱和，柔和而有层次。主体【固定角色设定】，在【符合时代地域的场景】中【一个具体动作】，关键物件【书籍锚点或已标记的示意物件】，通过【姿态、距离或物件位置】表达【本镜情绪】，采用【景别与机位】。视觉主体位于竖屏内容区，下方字幕带保持简洁，边缘预留轻微裁切空间。画面安静、克制、有生活质感，与【角色／代表镜头参考图】保持一致。无文字、无水印、单张独立画面。

**验收**：能看到油画笔触；暖色有灰度；面部不糊；无塑料皮肤；暖光没有覆盖真实情绪。

### S02 森系手绘绘本

**底与材质**：成年读者取向的手绘绘本。水粉平涂与柔软铅笔边缘、明显纸张颗粒；造型比 S01 更简洁，色块更平，不沿用厚油画笔触。

**建议配色**：鼠尾草绿 `#9AA88B`、苔绿 `#65765B`、奶油白 `#F2EBD7`、浅杏 `#E2B98C`。

**构图与叙事**：自然与生活结合；人物可以在屋檐下休息、整理包、照料植物。森林不是固定背景；植物必须服务当下场景，避免泛用绿景壁纸。

**运动**：一处轻微叶动、人物一个小动作或缓慢推近；不让整张纸呼吸变形，不做幼儿动画式弹跳。

**完整提示词模板**：

> 为成年读者的情感书评绘制单张9:16手绘绘本插画。鼠尾草绿、苔绿、奶油白和浅杏色，水粉平涂色块与细腻纸张颗粒，柔软铅笔边缘，圆润但不幼稚的人物，明确区别于厚涂油画。主体【固定角色设定】，处于【与文案有关的生活或自然场景】，正在【一个具体动作】，关键物件【可信锚点或标记为示意的物件】。用【动作与空间关系】表达【情绪】，采用【景别与机位】，柔和漫射光，前中后景简洁可辨。主体避开顶部小字和中下字幕带，底部低信息量，裁切后仍完整。与【参考图】保持角色和材质一致。无文字、无水印、无多格拼图，避免夸张大眼睛、玩具广告质感和厚油画笔触。

**验收**：与 S01 的画材有明显区别；绿色不压暗面部；人物不幼儿化；有文案动作和书籍锚点。

### S03 蓝灰胶片插画

**底与材质**：二维手绘电影分镜，手绘边缘与细颗粒。可接近电影构图，但始终是插画，不转成真人剧照。

**建议配色**：蓝灰 `#52616B`、灰青 `#344B55`、深蓝 `#202E3C`、少量琥珀 `#C89251`。暗处仍有层次，手机观看能辨识脸与关键道具。

**构图与叙事**：人物间距离、空座、未寄出的信、门的两侧等；背影、物件近景与环境空镜交替。不能把所有遗憾都画成雨夜落泪。

**运动**：轻微拉远或横移；冷色结尾可以保留，不强制从悲伤变成希望。

**完整提示词模板**：

> 单张9:16竖幅电影分镜感手绘插画，清楚的二维绘画边缘与细微胶片颗粒。蓝灰、灰青和深蓝主色，只有一处低亮度琥珀光，低饱和、明暗有层次，暗处关键物件可辨。角色【固定人物设定】，位于【符合时代地域的具体场景】，正在【一个克制动作】，通过【人物距离、空位或物件位置】表达【具体情绪】，采用【景别与机位】。留出未说出口的空间，面部和关键物件避开中下字幕带，下方背景简洁，保留边缘裁切余量。与【参考图】保持一致。单张独立插画，无文字、无水印，不靠夸张泪水表达情绪，不转成真人摄影。

**验收**：冷暖有主次；暗处可读；有叙事关系；不靠雨、眼泪或霓虹套路堆情绪。

### S04 淡彩水彩散文

**底与材质**：透明水彩薄涂、局部铅笔轮廓、纸纤维与真实水渍边缘。部分物件边缘融入纸白，但主体不能消失。

**建议配色**：暖白 `#F5EEDC`、烟灰蓝 `#A7B7BF`、浅褐 `#B49A7C`、淡杏 `#E8C6A6`。

**构图与叙事**：以一个记忆细节为中心，例如搪瓷杯、衣袖、窗框或信纸。具体年代、器物和场景应来自本书，或明确标注为生活映射。

**运动**：柔缓推近、平移；画面可以渐显，但不让水彩纹理每帧重新生成。禁止强锐化与大片发光。

**完整提示词模板**：

> 单张9:16文学散文水彩插画，透明水彩薄涂，烟灰蓝、浅褐、淡杏和暖白纸底，局部精细铅笔轮廓，真实纸纤维与自然水彩晕染。主体【固定人物或物件】，在【时代地域准确的场景】中【动作或状态】，通过【有依据的记忆细节或已标记的生活映射】承载【情绪】，采用【景别与机位】。局部边缘融入未着色纸白，主体保持可辨，不画满所有细节，像记忆里仍然清楚的一小块。关键内容避开字幕区域，下方低纹理，预留裁切空间，与【参考图】保持一致。无文字、无水印、无多格画面，避免厚油画、塑料质感、强光晕和过度锐化。

**验收**：有透明水彩与纸白，不是油画加淡滤镜；在手机尺寸仍能读懂主体；字幕不被浅色复杂纹理淹没。

### S05 黑白版画

**底与材质**：木刻／亚麻油毡版画感，实际可见的刻线、黑白块面和纸面纤维。不是将油画去色，也不是柔软铅笔素描。

**建议配色**：墨黑 `#171714`、纸白 `#EDE5D4`、中灰 `#77756C`，小面积暗赭 `#9B603A`。

**构图与叙事**：普通人的劳动、整理旧物、起身、等待等有能动性的动作。表现尊严，避免把苦难变成观赏性的漂亮摆拍。

**运动**：静帧、缓慢平移或推近；刻线固定，不添加发光粒子与炫目转场。

**完整提示词模板**：

> 单张9:16黑白木刻版画感叙事插画，墨黑与纸白块面明确，黑白灰层次清楚，粗细变化的雕刻线与纸面纤维，只有小面积暗赭色点缀。人物【普通人的具体设定与符合时代的服装】，在【真实生活环境】中【一个有尊严且明确的动作】，关键物件【可信书籍细节或已标记的生活映射】，通过【身体姿态、劳动痕迹或空间关系】表达【情绪】，采用【景别与机位】。人物具有能动性，构图朴素有力量，关键轮廓避开字幕带，下方简洁，预留裁切余量，与【参考图】保持一致。无文字、无水印、单张独立画面，不做灰度油画，不美化苦难，不使用柔焦和强辉光。

**验收**：存在清晰的版画刻痕与块面；人物有尊严；粗线没有破坏手、脸和道具结构。

### S06 超现实纸艺

**底与材质**：纸层数量有限，可见剪纸边缘、纤维和层间投影，明确是纸艺；避免变成陶土、塑料玩具或游戏场景。

**建议配色**：奶油白 `#EDE3CF`、灰蓝 `#8195A1`、深灰蓝 `#465D6A`，小面积橘色 `#D58B48`。

**构图与叙事**：一镜只用一个隐喻。例如人物放下过大的纸箱后露出道路。先让观众看懂动作，再读懂观点；不是把月亮、楼梯、鲸鱼、星空堆在一张图里。

**运动**：轻微纸层视差或一个纸件动作；保留接触关系与阴影方向，不让纸层随机变形。

**完整提示词模板**：

> 单张9:16超现实剪纸拼贴插画，真实剪纸纤维、清楚的纸张切边、有限层数与柔和层间投影，奶油白、灰蓝、深灰蓝与少量橘色，同一纸张材质贯穿画面。只有一个清楚的视觉隐喻：【一个具体可描述的隐喻】。原创角色【固定人物设定】正在【一个动作】，表达【一个明确观点】，采用【景别与机位】，尺度和空间关系清楚，背景简洁。关键角色和隐喻物件位于字幕带上方，底部低信息量，预留裁切余量，与【参考图】保持一致。无文字、无水印、无多格画面，避免多个象征物堆砌、陶土、塑料和游戏渲染质感。本镜为情绪隐喻，不冒充原著情节。

**验收**：纸边与纸层阴影可见；隐喻无需长篇说明；不是简单将油画放进纸框；人物和物件接触关系合理。

### S07 电影静帧

**底与材质**：真人电影剧照质感，35mm 胶片，真实皮肤、衣物纤维与空间；浅景深，前中后景分层；低饱和电影调色；细腻胶片颗粒与轻微暗角。不是插画、游戏渲染、塑料皮肤或过度磨皮。

**建议配色**：近黑 `#101014`、暖灰 `#2A2C31`、米白 `#F2EEE6`、旧金 `#C9975A`；全片一个主色温，一处强调色，不逐镜换色调。

**构图与叙事**：单一明确主光源（窗、灯、门缝、街灯、天光）；主角固定同一人，优先背影、侧影、手部和局部，不看镜头；一镜一个动作；环境承担情绪，不直译抽象词。参考片常见的母题：窗、雨、灯、伞、走廊、车站。

**运动**：缓慢推近/拉远或轻微横移；颗粒和暗角固定；可用雨、尘、雾、光斑，但不要满屏粒子。转场用淡入淡出或轻压黑，不用花哨转场。

**完整提示词模板**：

> 单张9:16真人电影静帧，35mm 胶片质感，【主色温】低饱和电影调色，单一明确主光源【光源方向】。固定主角【年龄、脸型、发型、服装、体型】，以背影/侧影/手部出现在【真实空间】，正在【一个具体动作】，表达【情绪】，采用【景别与机位】。前中后景分层，浅景深，细腻胶片颗粒与轻微暗角；关键主体位于 y=240–1380，顶部 y=120–520 留书名卡，底部 y≥1600 保持低信息；同一主角跨镜一致，不看镜头。与【参考图】保持一致。无文字、无水印、无字幕、无多格画面；不要插画、游戏渲染、塑料皮肤、过度磨皮、畸形手、额外人物。

**验收**：一眼是真人电影感而不是插画；主光方向明确；人物与服装跨镜一致；暗部有细节但不是死黑；字幕区不压人物面部。

### 所有画风共用的电影镜头语言

参考片不只是一套配色，而是一套镜头语法。无论 S01–S07，都遵守：

- **单一主光源**：每镜说清光从哪来；不要同时打三束光。
- **前中后景**：至少两层空间；主体不贴在背景上。
- **同一主角**：年龄、发型、服装、体型跨镜一致；优先背影、侧影、手部，不让角色直视镜头。
- **一镜一动作**：一个动词，屏上真的发生；不用装饰堆叠代替叙事。
- **母题重复**：全片一个物件或空间反复出现，形成记忆点。
- **色彩走向**：开场冷/暗 → 中段一处强调色 → 落点回暖或更冷；不要每镜一个色调。
- **标题与字幕安全区**：顶部 y=120–520 留书名卡；中文主行约 76–78%H、英文副行 81–84%H，底边 ≤1594。

## 四、出图提示词的组装方法

每镜完整提示词 = **选定画风模板 + 本片固定角色与时代 + 本镜场景／动作／景别 + 光线与情绪 + 参考图 + 安全区 + 排除项**。

- 替换模板里的全部【变量】；不把占位符直接送给模型。
- 一次生成一张独立分镜图；不要求模型在一张图里拼完整部影片。
- 每镜都包含完整固定设定，不只写“同上”。不同模型之间不依赖上一轮隐含上下文。
- 优先复用角色参考图与已通过的代表镜头。模型支持时再使用 seed、参考强度等设置；相同 seed 不单独保证人物一致。
- 需要精确书封、书名、作者或原文时，使用核实后的素材与后期文字。原创封面不得冒充正式出版物封面。
- 同一角色的脸、发型、服装、身材与配饰不随镜头漂移；变化必须有剧情或时间依据。

**共用排除项**：

> 不要文字、字母、书名、字幕、水印、标志、拼图、多格漫画、广告排版；不要额外人物、面部融合、畸形手、多余肢体、关键道具变形；不要随机换画材、塑料皮肤、游戏角色质感、年代不符的服装与建筑；不要无关的雨夜、眼泪、星空和发光蝴蝶。

有负面提示词栏时放入该栏，否则作为正文约束；不假设各平台都接受同一 API 参数。

## 五、分镜到绘画的执行顺序

1. 按现有流程完成书评文案、事实底稿与温暖男声配音，以真实时间轴写分镜初稿。
2. 提取主情绪、情绪转折和书籍锚点，选择一套 S01–S07，完成视觉设定卡。
3. 回看分镜是否适合该画材；保留原有旁白与真实时间，不为换画风平均分配秒数。
4. 先画最难或最有代表性的一镜；有人物连续性时补角色参考图。确认人物、笔触、配色和安全区。
5. 为每镜单独生成完整提示词，逐镜出图、验收；不合格只重画相关镜头。
6. 将合格素材带入工程，按分镜做必要的推拉、位移、遮挡或纸层运动。若旁白需要具体动作，安排对应动画或关键状态，不能用无关推近代替。
7. 后期排书名、作者和字幕；抽两行字幕的原尺寸静帧，再缩至约360px手机宽度检查。
8. 渲染与终检仍按现有脚本执行，成片只合旁白。

在原分镜表的“画面”描述基础上，按需要追加字段：

| 镜头ID | 真实起止时间 | 对应旁白 | 画面性质与依据 | 景别与动作 | 完整绘画提示词 | 排除项 | 参考图／素材路径 | 后期运动 | 验收点 |
|---|---|---|---|---|---|---|---|---|---|

场景可以跨越多句，按真实情绪与动作分镜，不强制每句重画一张。结尾延续本书情绪，允许悲伤或开放结局，不强制转暖。

## 六、统一审核场景（只用于比较画风）

需要复核画风差异时，各套图使用相同人物与机位（S01–S06 可拼六宫格，S07 单独出图）：

> 一位约28岁的东亚女性，短黑直发，燕麦色开衫，侧坐在木椅上，膝上摊开无字书，安静看向窗外。右侧小圆桌放台灯和素色陶杯，窗台一株绿植，窗外为傍晚街区。平视中远景，人物、椅子、台灯和窗框位置一致，下方留出简洁的字幕带。

本场景属于原创画风审核样例，**不是任何指定书籍的原著场景**。

- S01：油画笔触和局部暖光；S02：水粉平涂、绿调与铅笔边缘；S03：蓝灰暗部与单一暖光。
- S04：透明水彩、纸白和晕染；S05：黑白版画刻线；S06：纸层、剪切边缘与窗外一条折纸道路的单一隐喻。
- S07：同一场景改为真人电影静帧，单一窗光、浅景深、胶片颗粒与暗角；验证人物真实感与跨镜一致性。
- 审核时先比画材差异，再看情绪、可读性和竖屏留白，不靠换人物来制造差别。
- 正式成片不使用多宫格；每镜交付单张9:16图片。

## 八、建工程与完整工作流接入

**S01–S07 已直接接入 `--world`。默认S01；B/C仅保留旧工程兼容。**

```bash
python scripts/new_film.py <工程> --world S01
# S01可换为S02/S03/S04/S05/S06/S07；补全 art-direction.json 后：
python scripts/prepare_art.py <工程>
# 用AI绘图工具按 art-prompts.md 出图，保存到各镜 image 路径
python scripts/prepare_art.py <工程> --check-images
python engine/render.py <工程> --sheet 16
python engine/render.py <工程> --det
python engine/render.py <工程> --jobs 4
python scripts/finalize.py <工程>
python scripts/check_film.py <工程>
```

| 文件／入口 | 职责 |
|---|---|
| `references/visual-styles.json` | 七套的统一编号、画材提示词、配色、字幕字族、辉光、颗粒与暗角配置 |
| `script.json` | 可填 `visual_style` 或 `review_style`；显式命令参数优先 |
| `art-direction.json` | 本片选定画风、真实片长、角色设定、逐镜动作、事实性质、图片与运动 |
| `art-prompts.md` | 准备脚本导出的完整逐镜提示词，交绘图工具执行 |
| `art-direction.js` | 自动导出的浏览器画风与素材清单 |
| `assets/` | 绘图工具实际生成的分镜图片 |
| `engine/art.js` | 图片预加载、按真实时间选镜头、轻微推拉和平移 |
| `film.js` | 应用七套配置、补具体动作、书名卡/尾卡、暗角与字幕 |
| `scripts/check_film.py` | 检查清单同步、缺图、竖幅尺寸、片长、字幕和纯旁白规则 |

- 已有工程用`--force`且没有显式画风或script.visual_style时，保留绘画清单的画风；同步标准分镜表的“画风：”头，正文保留。
- 新工程不指定 `--world` 时，依次读取 `script.json.visual_style`、`review_style`（也接受旧的`style`文风字段）映射，再回退S01。
- `prepare_art.py`先验证场景、动作、时代、原著依据与时间；`--check-images`再验证素材存在、可解码且接近9:16，至少540×960。
- 生成图片的材质不能由底色／辉光替代。脚本负责清单与接图，实际出图使用现有AI绘图工具，不隐式调用付费服务。
- 换画风时改`art-direction.json.style`并重新准备、出图；注册表配置变化也需重新准备，再渲染。已有图片不会自动重绘。
- 素材预加载完成后引擎才就绪；缺图会明确报错。按`t`计算运动，支持乱序`seek(t)`。
- 七套新工程不自动添加旧仪表、星点或鎏金卡。B/C老工程继续使用原骨架，既有影片不改写。
- `--force`会重建`film.js/index.html`，保留已有绘画清单与分镜表；已有影片的手写动画不可无意覆盖。
- 三条竖屏跑道及纯旁白规则继续有效；工程API见[engine.md](engine.md)，字幕只认[vertical.md](vertical.md)。
