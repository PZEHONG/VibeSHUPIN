# 文案 → script.json → 分镜表

> 新默认是逐书设计的 Remotion 动态书评：分镜按下文的旁白与事实规则编写，制作源为 `motion.json`。每镜记录物体、实际动作、观众理解、画面性质与依据；素材按实际方案准备。字段与素材接入见 [混合素材指南](remotion-mixed.md)。本文提到 S01–S07、art-direction 和 film.js 的部分仅适用于历史 Canvas 工程。

顺序固定：**先有文案，再有旁白，再有分镜表**。旁白的真实时长决定片长和每一镜的秒数，
不要先排一张时间表再往里塞话。

## 一、script.json：给配音用的分段稿

放在工程目录下（`projects/<片名>/script.json`）。把已确认书评按朗读意群分段，不固定段数；
一段就是一个情绪单元，段间 `gap` 是停顿（秒）。

```json
{
 "voice": { "name": "书单男声lc", "id": "452e8fa02a5d4b7499061ff2cf963047" },
 "segments": [
  { "id": "hook",     "text": "她一次都没有回头。这是《白夜行》最后一页。", "gap": 1.0 },
  { "id": "reaction", "text": "……", "gap": 0.9 },
  { "id": "heal",     "text": "……", "gap": 1.0 }
 ]
}
```

- `voice.id` 是 Fish Audio 的声音 ID，**固定用温暖男声**；要换声线先跟用户确认。
- `id` 用英文小写，会变成 `audio/vo/<id>.mp3` 的文件名。
- `text` 就是最终字幕的原文，不写表演指令、不写括号、不编原著引文。
- `gap` 常用 0.8–1.2；情绪重的那一段之后可以给到 1.5。
- 片长 = 所有分段 + gap + 开头 0.35s + 结尾 2.0s（`--lead` / `--tail` 可调）。
- 语速用 `--speed`（0.9 更克制）；生成后听一遍，哪段不对就 `--only <id> --force` 重配那一段，
  然后**不带 `--only` 再跑一次**重搭时间轴。

## 二、分镜表 storyboard.md：一镜一行

表头写清：片名、风格、叙述体（情绪导读 / 分析评论 / 金句书摘 / 情感散文）、画风（S01–S07）、画幅 1080×1920、配音声音与语速、片长、**"成片只有旁白，无配乐无音效"**。

| 时间 | 旁白 | 画面 | 观众明白了什么 |
|---|---|---|---|
| 0.00–4.50 | 她一次都没有回头。这是《白夜行》最后一页。 | 夜里，女人背影走进人群，光环收拢 | 先给结局，不解释 |
| 4.50–14.50 | …… | 片名浮出，镜头缓慢推近 | 这是哪本书、什么情绪 |

写每一行时问三件事（答不出就回"找形象"那一步）：

1. **这是什么**——叫得出日常名字的一样东西（一把伞、一串台阶、一盏纸灯），不是点线圈。
2. **它在干什么**——一个动词，屏上真的发生（挡住雨、一盏盏亮起来）。
3. **观众明白了什么**——和这句旁白是同一个意思，不是配图。

再遵守：

- 时间段直接取 `timings.json` 的分段边界，不要平均切。
- 一个场景至少撑两句旁白，每句只改一处；相邻两镜版式不要一样。
- 提问、命名、结论那一镜可以不画新东西，让上一镜停住。
- 结尾可回到开头的画面或道具；原创落点不加作者署名。已核实引文才附对应署名，并在事实表保留记录。
- 画面承接旁白句意，抽象评论可采用标明性质的隐喻，不要求每个抽象名词都变成实物。确需改动原创正文时重新交用户确认、同步 script.json 并重配音；引文不可为分镜改写，只能换画面或重新核选短引。

### 可选的四拍结构（用户指定金句体时参考）

默认情绪导读按已确认正文的处境、片段推进和落点自然安排；分析评论体按论述安排。口播自然引书一次时可同步书名卡，不需另留一段重复报幕。下表只供用户指定金句体时参考，秒数仅示意约45秒片，不能用于20秒片或覆盖真实配音时间。

| 拍 | 时间 | 镜头任务 | `role` |
|---|---|---|---|
| 钩子 | 0–3s | 近景/中近景；人物背对或侧对，暗背景一束主光；不解释 | `hook` |
| 书名卡 | 3–6s | 主体退到下半部或虚化；顶部 y=120–520 留白；后制叠“今日分享／书名／作者” | `title` |
| 书摘链 | 6–40s | 4–6 镜，一镜一个动作；全景/中景/近景交替；同一母题反复出现 | `scene` |
| 落点 | 最后3–5s | 安静、留白多；人物停住或离开；给最后一句或署名让位 | `closing` |

- 全片只保留 **一个反复出现的物件或空间**（伞、窗、灯、纸条、路口），不要每句换比喻。
- 固定一个主角：年龄、发型、服装、体型跨镜一致；优先背影、侧影、手部，不让角色直视镜头。
- 色彩写一条 **color script**：开场冷/暗 → 中段一处强调色 → 落点回暖或更冷；不要每镜一个色调。
- 相邻两镜至少换一次景别（远→中→近），但同一情绪段内保持同一光向。
- 镜头按语义与真实配音变化，不固定句数与镜头数；一个完整句可跨多屏字幕，不为配镜头改写引文。

## 三、事实边界（必须写）

分镜表末尾分两栏：

- **事实**：作者、出版年、人物关系、结局——每条给可追溯出处与核实状态，不能只写“已核对”。
- **引用记录**：原文、作品/作者、译者/版本、位置、说话者/上下文、核实依据和使用理由，沿用文案底稿；未知项写未知。
- **示意**：为画面服务的设计（伞、台阶、灯），写明"不是原著场景"。
- 文案里的判断是**解读**，不是原著引文；字幕和旁白都不得伪装成"书里写道"。

## 四、外观跟着风格走

| 文案主风格 | 优先 | 按内容调整 |
|---|---|---|
| 情感共鸣 | S03 蓝灰胶片插画 | 温暖日常用S01；要真人电影感用S07 |
| 文学治愈 | S01 暖光纸感油画 | 轻盈接纳用S02森系手绘绘本 |
| 遗憾告别 | S03 蓝灰胶片插画 | 回忆散文用S04淡彩水彩散文；雨夜/窗边用S07 |
| 人生感悟 | S01 暖光纸感油画 | 现实题材用S05黑白版画；抽象观念用S06超现实纸艺；余华式冷峻现实用S07 |

用户指定和书籍主题优先；拿不准选S01，不强制冷转暖。机器默认映射见 `references/visual-styles.json`，画材与完整提示词见 `references/worlds.md`。
一片固定主画风、角色与材质；字幕颜色含义全片一致（金=关键意象，玫红=痛）。

## 五、绘画清单与出图

在 `script.json` 可增加：

```json
{
  "book_title": "书名",
  "author": "作者",
  "review_style": "文学治愈",
  "visual_style": "S01",
  "segments": [
    { "id": "hook", "text": "如果一个人注定要离开……", "en": "If someone is destined to leave...", "gap": 1.0 }
  ],
  "closing": { "text": "这段往事，还留在那个下午。" }
}
```

上例closing为原创落点，不加作者署名。attribution仅用于可追溯的已核实引文。
这些是额外元数据，配音仍读取原有 `voice` 和 `segments`。省略 `visual_style` 时，按 `review_style` 映射；显式 `--world` 优先。
`segments[].en` 只做屏显英文副行，不参与配音；`en` 存在时中文该屏必须单行；先把正文按语义拆成符合显示限制的分段，拼接后保持原字原序，不为显示改写引文。`closing` 可选，出现时最后 2–4 秒显示落点句/署名；`title_card` 由 `book_title`、`author` 自动生成“今日分享／书名／作者”，默认 4–6.5 秒，可在 `art-direction.json` 改时间。

建工程会按真实配音分段生成 `art-direction.json`。一段对应的初始镜头只是起点，可按情绪再细分；时间必须顺序、不重叠、不超出真实片长。已有分镜表不会覆盖。
在清单补全 `visual.characters`、`visual.era_location`、`visual.motif`、`visual.color_script`、每镜 `scene/action/emotion/framing/kind/role`；
`kind`只接受原著场景、读者生活映射、情绪隐喻；`role`只接受 `hook/title/scene/closing`。原著场景同时填写 `evidence`，不编原著细节。
无人物时明确写“无人物”；`anchor`写本书可信意象，参考图放`reference_images`或全片`visual.references`。

```bash
python scripts/new_film.py <工程> --world S01
# 补全 art-direction.json，和本分镜表保持一致
python scripts/prepare_art.py <工程>
# 按 art-prompts.md 用绘图工具逐镜出图，保存到 image 对应的 assets/ 路径
python scripts/prepare_art.py <工程> --check-images
```

导出的提示词包含完整画材、人物、时代、动作、情绪、母题、色彩走向、镜头任务、安全区与排除项；每镜单独出9:16图。
提示词会固定“单一主光源、前中后景、浅景深、同一主角、不看镜头、一镜一个动作”；顶部 y=120–520 留书名卡，底部 y≥1600 留 UI。
`art-direction.js`是自动导出的浏览器清单，不手改；图片路径使用工程内相对路径和正斜杠。
`motion.type`可用 `none/push/pull/pan-left/pan-right`，`amount`为0–0.08；需要实际人物动作时在`film.js`补动画或关键状态。

分镜表在原有四列之外，按需要加“画面性质与依据／参考图／素材／完整提示词／运动／验收点”，与清单逐镜对应。
出图后先审代表镜头和人物一致性，再审字幕与时间轴；不把命令成功当成画面质量合格。
